# Words to know

Here are the words you will see most often in Tavernary.

| Word | Plain meaning |
| --- | --- |
| **Catalog** | The searchable list of projects. |
| **Project** | One thing listed in the catalog, such as an extension, frontend, or preset. |
| **Frontend** | An app or interface used to interact with an AI roleplay system. |
| **Extension** | An add-on that changes or extends a frontend or workflow. |
| **System Preset** | Reusable settings or prompting resources made by a creator. |
| **Source** | The creator's public repository or page where the project really lives. |
| **Repository** | A project folder managed by a code-hosting service such as GitHub or Codeberg. |
| **Kit** | An ordered collection of 3–50 catalog projects. |
| **Popularity** | A combined GitHub stars, forks, and watchers signal. It is not a quality score. |
| **Recent Activity** | The latest qualifying source change or release. |
| **Sustained Activity** | The number of active weeks in the latest 12-week window, shown as `N/12`. |
| **TavernKeeper** | Tavernary's advisory scan system, which combines deterministic security tools with contextual review. |
| **Scan evidence** | Information that helps you ask safety questions. It is not a guarantee or endorsement. |
| **Pending enrichment** | Tavernary is still waiting for a verified fact. It does not mean zero or confirmed missing. |
| **Curated** | A human-maintained description or classification. |
| **Provisional** | Information that is useful but still being checked or completed. |
| **Source health** | Whether Tavernary can still reach and safely identify the project's source. |

## A useful rule

Catalog words are clues, not magic answers. When you are ready to try a
project, open its source page and follow the creator's current instructions.
