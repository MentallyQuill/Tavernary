# Homepage Search Description Design

## Goal

Give search engines a clear, useful summary of Tavernary that emphasizes
SillyTavern and open-source discovery. Replace the current tagline-only
homepage description, which is too vague and can lead search engines to assemble
an awkward snippet from adjacent visible text.

## Approved Copy

> Discover open-source tools for SillyTavern and AI roleplay. Explore
> extensions, frontends, presets, and community-built Kits.

The wording presents open source as a discovery focus without claiming that
every catalog listing is open source.

## Metadata

Use the approved copy as the root page's HTML meta description. Keep
`Where AI roleplay tools gather` as the visible brand tagline; the tagline and
search description serve different purposes.

Add matching Open Graph and X/Twitter descriptions so search results and shared
links present the same message. Keep the existing page title and icons.

## Verification

Add focused metadata coverage that renders the root layout or inspects the
static export and confirms:

- the standard description matches the approved copy;
- Open Graph and X/Twitter descriptions match it;
- the visible brand tagline remains unchanged; and
- the production static export contains the expected description tags.

Search engines retain control over displayed snippets, so deployment cannot
guarantee immediate or verbatim adoption. Success means Tavernary publishes
consistent, descriptive metadata that crawlers can select after recrawling.
