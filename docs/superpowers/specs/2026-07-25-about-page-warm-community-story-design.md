# About page warm community story

## Goal

Rewrite the About page so it welcomes visitors into Tavernary's purpose and
community story while retaining a concise, trustworthy explanation of what the
site does.

## Content direction

Keep this opener verbatim:

> Tavernary is a search and discovery catalog for AI roleplay tools, surrounding
> the SillyTavern community. It indexes public project information and sends
> visitors to each creator's own GitHub repository or source page.

Follow it with four story beats:

1. **Why Tavernary exists:** Useful tools are scattered across Reddit posts,
   Discord channels, creator repositories, and word of mouth. Tavernary brings
   discovery into one welcoming place.
2. **Built for exploration:** Visitors can search projects and creators, browse
   Frontends, Extensions, and System Presets, and use the catalog's discovery
   filters.
3. **Make it yours with Kits:** Kits are user-tailored collections. Visitors
   can browse, assemble, reorder, save locally, share, and submit Kits rather
   than receiving one Tavernary-prescribed bundle.
4. **Trust and ownership:** Keep a short closing note that Tavernary links to
   creator-owned sources rather than hosting project files, and that inclusion
   is not an endorsement.

Describe PCPartPicker and Reddit as inspiration and shared spirit, not as a
formal partnership or historical claim about Tavernary. The intended framing is
that PCPartPicker demonstrates the value of bringing scattered community
knowledge into one place so people can build what suits them, while Reddit and
Discord are examples of where this community's discoveries currently live.

## Scope boundaries

Do not add maintainer-facing GitHub refresh, enrichment, repository snapshot, or
moderation mechanics. Keep the existing Submit a project and Get help actions.
Do not imply that Tavernary hosts, installs, or redistributes project files, or
that Kits are server-side personal collections.

## Verification

Review the rendered copy for the exact opener, welcoming tone, and absence of
unsupported PCPartPicker partnership/history claims. Run the applicable format,
lint, typecheck, production build, and static-export checks.
