# Tavernary longevity verification ledger

The approved scope is GitHub-only unattended operation, with inline implementation
and independent branch review. External watchdogs, off-site backups and automatic
project discovery are excluded. Routine publication preserves immutable identities,
Publisher custody, owner decisions, tombstones, manual mode and catalog/Companion
contracts. Account recovery, credentials, billing, domain renewal and exceptional
policy decisions remain owner responsibilities.
